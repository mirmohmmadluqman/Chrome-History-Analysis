# ChronosAnalytics

Advanced browser intelligence and productivity analytics for Chrome.

## Features
- Active engagement time tracking
- Intent-based domain categorization
- Personalised goal optimization via Gemini AI
- Local-first data storage and privacy

## Setup
1. Clone the repository.
2. Open `chrome://extensions/`.
3. Enable 'Developer mode'.
4. Click 'Load unpacked' and select the project directory.

## Privacy
All tracking and analytics data is stored locally in your browser. No data is sent to external servers except for voluntary Gemini API calls for goal optimization.
